Welcome to Token Huddle

Token Huddle shows how much of each AI coding tool's usage limit you have used, in one small window. This is what it found on this computer.

    What Token Huddle never touches

    • Your logins, tokens or credential files for any tool.
    • The network, except to find updates and fetch one when you click (Settings turns it off).
    • Another tool's settings, unless you click Connect and approve the change.
    You can connect later from Settings.

    Your subscriptions

    Token Huddle finds the coding tools on this computer and shows one card for each. It never reads or uses their logins.

      Alerts

      A Windows notification when a card's usage passes these levels, once per limit until it resets. Turn alerts off for one card with its Alerts switch.

      Updates

      You have version . Token Huddle checks this project's GitHub Releases for a newer one; nothing is downloaded or installed until you click.

      Add another account

      If you keep a second account of a tool in its own folder (for example a work login), add it here. The folder is checked before it is saved.
